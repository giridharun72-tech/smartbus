Signal Loss Fallback Workflow
  1. Automatic Heartbeat detector monitors GPS updates every 5 seconds.
  2. If a bus drops transmission for >30s, status shifts to GPS_SIGNAL_LOST.
  3. BCU reviews last known location and contacts driver or enables Manual Location Mode.
  4. Driver interface receives permission to submit coordinates manually.
  5. Passenger maps update immediately with label MANUAL LOCATION UPDATE.
